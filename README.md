# ShengMengping.github.io

Personal homepage and resume of Mengping Sheng (QS Assistant).

Built with [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) Jekyll theme, deployed to GitHub Pages via GitHub Actions.

## Local Development

Requires Ruby >= 3.1 and Bundler:

```bash
bundle install
bundle exec jekyll serve
```

## Deployment

Push to `main` — GitHub Actions builds and deploys automatically to https://ShengMengping.github.io/
